# RetentionLab

Data-Driven Hook Analysis and Viewer Retention Prediction
for Short-Form Video Content.

## Project Structure
- data: Dataset storage
- notebooks: Jupyter notebooks
- src/data: Data preparation
- src/analysis: Exploratory data analysis
- src/models: Machine learning models
- src/visualization: Charts and visualizations
- app: Streamlit prototype
- docs: Project documentation

## Setup
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

## Run
streamlit run app/app.py
